アプリの使い方
amsの機能と使い方ガイド
touch_app
基本操作
1
時間割のコマをタップすると、その授業の記録画面が開きます。
2
出席・遅刻・欠席・出席なしのいずれかを選んで記録します。
3
記録するとセルに出欠数が表示され、統計・履歴・警告に自動反映されます。
swipe
画面下のトグルで「時間割」と「今日」を切替。左上の≡メニューから統計・履歴・警告・設定へ移動できます。
how_to_reg
出席を記録する

記録画面で日付と時刻を指定し（初期値は現在時刻）、ステータスを選びます。

check_circle
出席通常の出席
schedule
遅刻出席率は0.5換算
cancel
欠席出席率0
block
出席なし休講・出欠不問

記録一覧から個別記録を削除でき、授業回数（全体）を設定できます。これが警告や欠席アイコンの基準になります。

merge
同じ授業名のコマ（週2回ある科目など）は、出欠数が自動で合算されて集計されます。
percent
出席率と警告のしくみ

出席率は記録回数のうち、出席・遅刻の重みづけで計算されます。

出席率 ＝ 出席×1 ＋ 遅刻×0.5 ÷ 記録した総回数

「出席なし」はこの計算に含まれません。

警告は2種類。基準を超えると、時間割や統計で科目名がブランドカラーになります。

block
欠席回数で警告：残りの許容欠席数が設定値以下になると警告。
percent
出席率で警告：出席率が設定値（初期60%）を下回ると警告。
許容欠席数 ＝ 全授業回数 ÷ 3（端数切り捨て）
tune
基準の回数・％はメニュー › 警告から変更できます。遅刻は0.5回分の欠席として数えます。
grid_view
欠席アイコン

各コマに、許容欠席数に対して今どれだけ欠席したかが一目で分かるアイコンが出ます。遅刻は半分ぶんとして数えます。

apps
simple：ドット表示。塗りが欠席ぶん、グレーが残り許容数。
draw
kanji：「正」の字で表示。書き順どおりに欠席が積み上がります。
palette
表示スタイルは設定 › スタイル › 欠席数アイコンのスタイルで切替できます。
show_chart
出席時刻の分析

記録画面の「出席確認時刻の推移」グラフで、毎回の出席登録時刻の傾向が見えます。点線は平均です。

sync_alt
時限換算：別の限の時間帯（前後5分の余裕つき）で記録された時刻は、自動でこのコマの時限に換算。二重リングの点が換算済みです。
filter_alt
外れ値：記録一覧のfilter_altボタンで指定すると×印になり、平均から除外されます。
insights
この平均・最早・最遅は、今日の予定の「出席まで」カウントダウンにも使われます。
splitscreen
今日の予定（タイムライン）

その日の授業を時刻軸のタイムラインで表示。現在時刻のラインが今どこにいるかを示します。

timer
上部カードに「出席まで」のカウントダウン。過去記録から最早・平均・最遅の3目安を毎秒更新します。
bar_chart
軸の横の帯は過去の出席時刻の範囲。濃い帯は中心50%（四分位範囲）です。
swipe
カードは左右にスワイプ／矢印で、次のコマの出席予測へ切替できます。
bar_chart
統計

メニュー › 統計で全体の状況をまとめて確認できます。

summarize
要約：出席・遅刻・欠席・出席なしの合計と、全体の出席率。
local_fire_department
連続出席：出席が続くほど増加。欠席・遅刻でリセット。最高記録も残ります。
pets
フル出席：その日の対象授業をすべて出席（または出席なし）で埋めると、犬が登場してカウント＋1。
calendar_month
カレンダー：日ごとの記録をドットで可視化。
list_alt
履歴とバックアップ

メニュー › 履歴で全記録を一覧でき、出席・遅刻・欠席で絞り込めます。

save
JSONバックアップ：全データをファイルに保存。あとから完全復元できます。
table_chart
CSV／TXT出力：表計算ソフトや提出用テキストとして書き出し。
warning
データは端末のブラウザ内に保存されます。機種変更やキャッシュ削除に備え、JSONバックアップは定期的に。（ログインすればクラウド同期されます）
edit_calendar
時間割の編集とプリセット
edit
編集：コマの追加・削除や、授業名・教員・教室・曜日・時限の変更。
grid_on
プリセット：学年・学期（M1F〜M4S）を選ぶと、その時間割をまとめて読み込めます。
event_busy
出席を記録しない科目：休講科目などをグレーアウトし、集計対象から外せます。
palette
見た目のカスタマイズ

設定 › スタイルでアプリの見た目を調整できます。

format_color_fill
カラーテーマ：ブランド色・背景・出欠の色などを自由に変更。いつでも初期化できます。
drag_indicator
セルの表示項目：教員・教室・回数などの表示/非表示とドラッグ並べ替え。
animation
スプラッシュ画面の表示や、欠席アイコンのスタイルもここで設定。
cloud
ログインとデータ同期

≡メニュー › ログイン / 新規登録からアカウントを作ると、データがクラウドに保存されます。

devices
スマホとiPadなど複数端末で同じデータを使えます。変更は自動同期。
login
ユーザー名とパスワードだけで登録OK。登録時、今あるローカルデータはそのまま引き継がれます。
info
ログインしなくても、ほぼすべての機能はそのまま使えます。
group
共有とフォロー

ログイン後、マイページから友だちと出席状況を共有できます。

link
共有URL：URLを発行すると、知っている人があなたの時間割・出席状況を閲覧専用で見られます。いつでも無効化可。
person_add
フォロー：ユーザー名で検索して申請。承認されると相手の時間割を見られます（公開アカウントは申請なしでフォロー可）。
